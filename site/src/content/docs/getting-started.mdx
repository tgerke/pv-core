title: "Getting started"
---

pv-core runs locally with Node and Docker. The whole stack (Postgres, REST API, and web
app) comes up in a few minutes with a seeded demo: two sponsors, three trials, and ten
cases sitting at every point of the regulatory clock. Standing it up is a developer task;
once it is running, the [user guide](/pv-core/user-guide/) covers everything from there
without code.

## Prerequisites

- Node 22+ and [pnpm](https://pnpm.io)
- Docker (for Postgres 16, MinIO, and mailpit)

## Run it

```sh
cp .env.example .env
pnpm install
pnpm db:up        # Postgres 16 on :5436, MinIO, mailpit
pnpm db:migrate
pnpm db:seed      # two sponsors, three trials, ten cases
pnpm dev          # API on :8789, web on :5176
```

Open `http://localhost:5176` for the case queue and `http://localhost:8789/docs` for the
interactive API reference.

## Who you are in the demo

`AUTH_MODE=dev` maps five bearer tokens to seeded people. The web app's persona switcher
(top right) moves between them; scripts pass them as `Authorization: Bearer <token>`.

| Token | Person | What they can do |
| --- | --- | --- |
| `dev-admin-token` | Dana Whitfield, CRO administrator | Everything, across both sponsors |
| `dev-processor-token` | Marcus Lee, case processor | Intake, data entry, follow-ups, submissions and acknowledgements, for the main sponsor only |
| `dev-reviewer-token` | Priya Raman MD, safety physician | Assessments, expectedness overrides, unblinding facts, waivers, signing, for the main sponsor only |
| `dev-readonly-token` | Sam Okafor, auditor | Read everything, change nothing |
| `dev-ingest-token` | EDC intake service | Create cases from a source system; read nothing back |

Dev mode is a demo affordance. A pilot runs `AUTH_MODE=oidc` against your identity
provider ([deployment](/pv-core/compliance/#honest-gaps-current-phase)).

## What the seed shows

The queue opens with the cases the demo is built around: a fatal SUSAR whose 7-day clocks
are due in three days, a case whose 15-day clocks are five days overdue, one submitted and
acknowledged, one serious but expected (no clock at all), a follow-up whose new
information restarted a 15-day clock, a nullified duplicate, a placebo subject whose
obligations were waived after unblinding, and an intake item from the EDC that is not yet
a valid case. Re-run `pnpm db:seed` at any time to reset it; the dates are relative to
today.

## MedDRA

The demo dictionary is a labeled illustrative subset with synthetic codes; it is not
MedDRA. To code against a real release, load the ASCII distribution your organization
licenses:

```sh
pnpm db:import-meddra -- --version 27.1 --dir /path/to/MedDRA/ascii-27.1
```

Nothing licensed ever ships in the repository ([ADR-0005](/pv-core/decisions/#adr-0005)).
